## Адреса и доступ

- Единый сервис команды: https://5gofnn1dvheh3y-8000.proxy.runpod.net
- API: `POST /api/v1/analyze`, `GET /api/v1/jobs/{job_id}`.
- Документация: https://5gofnn1dvheh3y-8000.proxy.runpod.net/docs
- Проверка процесса: https://5gofnn1dvheh3y-8000.proxy.runpod.net/health
- Локальный сайт, подключённый к этому API: http://127.0.0.1:8002/
- Ключ передаётся жюри отдельно закрытым каналом; в общем комплекте и JS его нет. Это один ключ единого сервиса, заголовок `X-API-Key`.

**Публичный UI по корневому адресу пока не принят:** на предыдущей проверке `/` возвращал404. После установки комплекта ML-инженером нужно отдельно проверить внешний адрес из чистого браузера. Локальный URL не подходит для сдачи жюри.

## Минимальный отчёт ML-инженера без приватного содержимого

Сообщить только: release SHA, health model_loaded, HTTP статусы auth, число протестированныхpositive/negative/multiple, число несовпадений при ручной проверке, максимум общего времени, число failed, offline проверен/нет, restart проверен/нет, свободный диск и факт установки UI. Не присылать исходные видео, кадры, подписи эпизодов или ключ.

При ошибке вернуть предыдущий entrypoint и снять статус готовности. Не менять модель и зависимости одновременно с HTTP/UI без отдельной необходимости. После приёмки — freeze до завершения проверки жюри.

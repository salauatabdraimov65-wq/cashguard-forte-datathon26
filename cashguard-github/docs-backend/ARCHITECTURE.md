# Архитектура решения

## Подтверждённая текущая схема

Браузер → единый FastAPI-сервис команды на Runpod → один загруженный ML pipeline → результат задания → браузер или API жюри. `X-API-Key` одинаков для сайта и API жюри. Отдельная публичная служба жюри не требуется. Статику React/TypeScript/Vite можно выдавать этим же FastAPI по `/` и `/assets`; API не перехватывается SPA fallback.

Локальный `backend.preview` на127.0.0.1:8002 служит только транспортом к фиксированному HTTPS origin. Он не запускает модель, не создаёт очередь заданий, не повторяет POST автоматически и не хранит ключ. Старый synthetic-сервис8000 сохраняется отдельно для разработки и не является ML-релизом.

## Модели — по полученному serve_plus.py

- `src.pipeline.Analyzer`: YOLO11m для людей, YOLO11m-pose для поз, собственные cash/object-веса `models/cash_yolo11m_auto.pt`.
- Локальный мультимодальный `Qwen/Qwen3.5-9B`, `tta=False`.
- `addon.AnalyzerPlus`, включён только блок `audit`: проверка состояния в конце клипа. Блоки `checklist` и `safety` в полученной конфигурации выключены.
- Имена VideoMAE/X3D из раннего обсуждения не подтверждены как часть этой конфигурации.

Исходный factory берёт веса/кеш из `/workspace`, включает `HF_HUB_OFFLINE=1`. Пользователь подтвердил, что весь pipeline, включая Qwen, использует локальные веса без сторонних AI API. Это подтверждение команды; полный аудит импортируемого `/workspace/app/src/`, сетевого трафика и реальный запуск без внешнего egress отдельно не выполнены. Состав runtime сохраняет ML-инженер; установка зависимостей нашего Mac поверх GPU-окружения не предусмотрена.

## Подготовленный релиз

`serve_release.py` предназначен заменить HTTP-обвязку, сохранив factory модели. `addon_release.py` оборачивает уже загруженный add-on без второго экземпляра модели, изменения весов или обучения. `forte_site.py` выдаёт готовый frontend. Применение на Pod и совместимость фактической GPU-среды подтверждаются только после согласованного перезапуска и приёмки; подробности и точные гарантии — в INSTALL и PROVIDER-HARDENING.

Нормативный каталог хранится отдельно от модельного вывода. Он содержит документы и условные кандидаты, автоматическое подтверждение применимости отключено. XLSX с разбором учебных видео не используется как lookup по имени нового файла.

## Следующий промышленный этап

После конкурса потребуются предметная и правовая валидация, независимый датасет и метрики по классам/ракурсам, изоляция декодера и GPU-worker с восстановлением после зависания, проверенные квоты, управление пользователями и сроками хранения, журналы доступа без содержимого видео, мониторинг, резервирование и согласованные процедуры банка. Это не объявляется выполненной промышленной готовностью.

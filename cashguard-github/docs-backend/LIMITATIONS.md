# Известные ограничения

- На18.10 проверен настоящий сайт → Runpod на одном сгенерированном трёхсекундном видео. Он дал `no_violation` примерно за3секунды. Это не оценка accuracy, полноты событий, устойчивости или предела300секунд на длинных роликах.
- Положительные/множественные результаты и ошибки UI проверены отдельно на синтетических fixtures; их нельзя выдавать за результаты модели.
- Пользователь сообщал80% accuracy, docstring factory упоминает85%clean/79%mirror. Независимого подтверждения методики/holdout для текущего сервиса нет. Другой сохранённый cached replay67.5% измерял иной объём без нового VLM-инференса; сравнивать эти числа напрямую нельзя.
- Полный код основного pipeline не получен. Наличие локальных весов/кеша и offline-переменной не доказывает отсутствие всех внешних обращений.
- Нормативные ссылки проверены выборочно по официальным текстам; условия применения к каждому событию, вся история вступления поправок и базовые описания модели не подтверждены. Автоматический правовой вывод не предоставляется.
- Существующий addon мог скрывать сбои и исчерпание собственного бюджета. Подготовленная обёртка отказывает при таких сбоях; это может увеличить число явно не обработанных видео, зато не подменяет неполный анализ отрицательным вердиктом.
- Лимиты128MiB/180секунд/1920px/60fps и20событий — политика команды, не гарантированная граница скрытых тестов. При превышении нужен явный отказ, не молчаливое обрезание.
- Один GPU-job без очереди: параллельная загрузка получает busy. Длительный native/GPU-вызов нельзя безопасно убить обычным Python thread; до его завершения новый анализ не допускается. Полная изоляция декодера/GPU и автоматическое восстановление требуют отдельной проверки/доработки.
- Статика и новая HTTP-обвязка подготовлены локально; их установка на действующий Pod и проверка после перезапуска ещё не подтверждены.
- `/workspace` считается сохраняемым по сообщению команды; фактический persistent volume и поведение после terminate Pod здесь не проверены. Это нельзя считать резервной копией.
- Ручной screen reader отложен пользователем; axe не заменяет VoiceOver и полную проверку доступности. В текущем browser QA часть contrast-проверок incomplete; visual regression без утверждённого baseline inconclusive.

Технический сбой должен возвращаться как failed/ошибка, а не как `no_violation`. Никакие заявленные проценты и неопределённые нормативные связи не подставляются как измеренный факт.
